# 学習ライブラリ分類設計

## ステータス

この分類設計を、質問型学習ライブラリの確定方針とする。

- 大分類: 必須、1つ
- 中分類: 必須、1つ
- 専門領域: 任意、1つ
- 関連分類: 任意、最大3つ
- 概念: 複数指定可能
- 年代、地域、人物、組織、作品、制度: 分類とは別のファセット
- AIは登録済みIDから分類し、分類名を勝手に追加しない
- 専門領域の確信度が低い場合は、中分類で止める
- 回答データは1件だけ保存し、複数分類から同じ回答を参照する
- 空の専門領域は画面に表示しない

## 表示ルール

一覧では分類を1行に収める。

```text
人文科学 › 歴史 › 近代ヨーロッパ史
```

画面幅が狭い場合は中分類以降を優先する。

```text
歴史 › 近代ヨーロッパ史
```

関連分類、概念、年代、地域などは詳細画面の折りたたみ情報として表示する。

## 別軸ファセット

分類とは別に、必要な項目だけを保存する。

- 年代: 年、世紀、時代区分、開始・終了
- 地域: 世界、大陸、国、地域、都市
- 人物: 正規化した人物ID、表記、別名
- 組織: 国家、政府、企業、国際機関、団体
- 作品・資料: 書籍、論文、芸術作品、法律、条約、統計
- 適用範囲: 普遍的原理、特定時代、特定地域、事例
- 問いの型: 原因、仕組み、比較、定義、経緯、影響、評価、方法

## AI分類ルール

1. 質問に登場する名詞ではなく、回答の中心となる説明原理で主分類を選ぶ。
2. 大分類と中分類は必ず登録済みIDから1つずつ選ぶ。
3. 専門領域は登録済み候補と明確に一致する場合だけ選ぶ。
4. 専門領域の確信度が低い場合は `null` とし、中分類で止める。
5. 関連分類は、回答理解に実際に必要な場合だけ最大3つまで付ける。
6. 固有名詞や個別現象を新しい分類にせず、概念またはファセットにする。
7. 同義語は既存の正規化概念へ統合し、表示名と別名を分けて保存する。
8. 分類不能な項目は `interdisciplinary > unclassified` に置き、分類を捏造しない。

## 分類例

### なぜ空は青いのか

- 大分類: 自然科学
- 中分類: 物理学
- 専門領域: 光学
- 関連分類: 地球科学、気象・大気科学、化学
- 概念: レイリー散乱、波長、太陽光、大気
- 適用範囲: 時代に依存しない自然現象

### なぜフランス革命は起きたのか

- 大分類: 人文科学
- 中分類: 歴史
- 専門領域: 近代史
- 関連分類: 政治学、経済学、思想史
- 概念: 身分制度、財政危機、啓蒙思想、革命
- 年代: 18世紀後半

### なぜ金利が上がると株価が下がりやすいのか

- 大分類: 社会科学
- 中分類: 経済学
- 専門領域: 金融経済
- 関連分類: 投資、金融市場、企業金融

- 中分類: 経済学
- 専門領域: 労働経済

- 適用範囲: 現代および将来予測

## 将来の拡張

- 分類辞書には `version` を持たせる。
- 表示名を変更しても安定IDは変更しない。
- 新しい分類候補は既存項目への影響を確認してから追加する。
- 分類変更時も質問、回答、関連、出典、履歴は保持する。
- 分類は閲覧経路であり、回答本文を重複保存する理由にしない。
